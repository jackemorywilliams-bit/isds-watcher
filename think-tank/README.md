# Think-tank vault

A small **Obsidian-ready** vault for thinking through open design questions for this project —
starting with the multi-agent program. Markdown notes with `[[wikilinks]]` and `#tags`, so
Obsidian's graph view and backlinks work out of the box.

## Open it in Obsidian
1. Open Obsidian → **Open folder as vault** → choose this `think-tank/` folder
   (or copy `think-tank/multi-agent/` into your existing vault).
2. Open `multi-agent/[[_MOC]]` (the Map of Content) and follow the links; use the graph view.

It is versioned in the repo, so edits are tracked. Start at `multi-agent/_MOC`.
