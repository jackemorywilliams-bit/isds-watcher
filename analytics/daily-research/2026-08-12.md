### An instrument finding I did NOT pre-register, found by reading the result

**Three rows fetched the identical URL in one run, returned identical byte length 106011, and three
DIFFERENT sha256 digests:** `69f9be2b87da12a6…` (row 2), `06343aa3cd796caf…` (row 3),
`24d613de6eb611b1…` (row 4).

I checked from code before asserting this, because the obvious alternative is that `find` contaminates
the digest. It does not: `scripts/fetch_relay.py:171-177` sets `bytes = len(content)` and
`sha256 = hashlib.sha256(content).hexdigest()` over the **raw response body**, while `find` reaches
only `excerpt` and `find_matched`. So the three digests are three genuinely different byte strings of
identical length, served for one URL inside one run.

**Consequence, and it bears directly on a method this council adopted yesterday.** Yesterday's D1
concluded that a resource was unchanged from **length equality plus SHA-256 equality**. That direction
is untouched. But the converse — *digest inequality shows the document changed* — is **refuted for this
host**: here it shows only that some constant-length element differed between two responses. Any future
change-detection built on digest inequality would have fired three times today on one unchanged docket
page.

**And a second observation, arithmetic and checkable.** Between yesterday's run and today's, on this
host: the case page went **105,924 → 106,011 bytes**, and the press release went **47,929 → 48,016
bytes.** Both are **+87 bytes exactly.** Two different documents, one host, one day apart, the same
delta.

**What this does not exclude, stated plainly.** I hold no body, so I cannot say *what* differs. The
natural reading — that the +87 sits in shared page furniture rather than in either document's
substance — is an **inference and is labelled one**. It does not exclude coincidence (two independent
87-byte changes), nor that each document genuinely changed by 87 bytes, nor any mechanism for the
within-run digest variation (a rotating token, a nonce, a constant-width timestamp would each do it;
I can distinguish none of them). What is established is the arithmetic and the code path, and those
are enough to say that **byte length and digest on this host track the template at least as much as
the document**, which is a caveat the D1 method did not carry.

This was not pre-registered. It is an observation from reading the artifact, not a tested proposition,
and it is recorded at that weight.
