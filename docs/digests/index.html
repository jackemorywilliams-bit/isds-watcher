Digest Archive

Each run is archived below, newest first. The schedule is a Monday run, but the archive is what actually happened: some runs fell on adjacent days, so these are dated runs rather than one-per-week observations. Open a date to read the formatted digest: its run summary followed by one annotated entry per surfaced development, with the source named, linked, and its URL shown in full.

What the runs show

Two views of the archive, built from each run’s recorded counts: how the volume of candidates evaluated and items surfaced has moved from run to run, and which catalogue sources contributed the items that reached a digest. No item has yet reached the relevance threshold, so the match line sits at zero across every archived run — these charts track screening volume, not findings. The runs are not evenly spaced and the source roster changed during the period, so the series is a record of what was collected, not a controlled measurement.
