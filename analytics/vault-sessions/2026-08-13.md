## 4. Orphan check — and a correction to this seat's own convention

**The clone was shallow.** `.git/shallow` was present and the first orphan pass ran against a
truncated object set. Every result below is from after `git fetch --unshallow`.

`--is-ancestor` — the convention this note has used since 2026-08-04 — reports **45** unlanded
branches. `git cherry` (patch equivalence) reports **6**. The difference is squash-merged branches,
whose tips are correctly not ancestors. Of the six:

| `feat/research-council` (2026-06-22) | Old; `METHODOLOGY.md` + rebuilt `docs/`. Not this seat's paths. |

**Nothing else is committed-but-unlanded.** The 08-08 through 08-12 council work all landed.

**F2 re-tested on the full history and the loss is confirmed.** The 887-line
`analytics/council-sessions/2026-08-03-standing-rules.md` appears in **no commit on any branch**;

source material. `scripts/check_sources.py` fails the same way — 5 failures, by design, since it

`test_pipeline.py -k`, `test_headline_lane.py`, `test_check_lock.py`, `test_rings.py`,
`test_classify_v2.py`, `test_triage.py`), and the other workflows each run one guard's tests.
`test_one_pagers.py` runs nowhere in automation.

This is not a defect to fix — the PDFs are copyrighted and correctly untracked. It is a
**measurement caveat that the vault has never stated**: "564 passed" is a fact about one laptop.
