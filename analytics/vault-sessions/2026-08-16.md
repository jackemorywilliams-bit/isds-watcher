## FOR EMORY — 10. Found on landing: the currency guard cries drift on its own maintenance

This one was found *after* the session merged, by re-running the guard on `main`, and it is the
reason a record should always be re-checked once it lands.

`scripts/check_currency.py` went from **1 failed to 3** the instant this session's commit
`5138312` merged — reporting [[Project Change Log]] and [[Workflow Threads]] stale **against the
very commit that wrote them**. That is a false positive.

The guard anticipated exactly this. `_is_maintenance` (`scripts/check_currency.py:93-105`)
exempts a commit "whose every changed file is itself a tracked note", and its docstring reasons
correctly that "no fully committed tree can ever pass this guard" otherwise. But it implements
that as `files <= set(TRACKED)`, and `TRACKED` lists only four index notes plus
`STATE_OF_THE_ANSWER.md`. **A real archivist session commit can never qualify**, because it also
writes its session record, the seat notes it corrected, and `HANDOFF.md`:

| Session commit | Files touched | Tracked | Exemption fires? |
|---|---|---|---|
| `5138312` (this session) | 8 | 4 | **no** |
| `67c80f7` (2026-08-13) | 7 | 3 | **no** |

**It has happened twice and was missed once.** On 2026-08-13 the guard printed
`agents/Project Change Log.md … 67c80f7 vault: archivist session 2026-08-13`, and that session —
mine — read it as ordinary staleness and restamped. A guard that reports drift on its own
maintenance teaches its only reader to skim it, which is precisely the failure it exists to
prevent.

**Not fixed by me:** `scripts/` is outside this seat's merge authority. **And I deliberately did
not restamp the anchors to the merge commit** — an anchor must name the commit the audit ran
against, and `5138312` did not exist then. Papering over a false positive would be the worse
defect. Opened as **C17**, owner [[systems-designer]]: widen the exemption to match its own
stated rationale — every changed file a vault record surface (`agents/`,
`analytics/vault-sessions/`, `moc/`, `HANDOFF.md`) rather than one of five named notes. Any
commit touching a substantive path still counts, so the guard keeps its teeth.
