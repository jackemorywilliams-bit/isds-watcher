# 00 — The question

**Should the ISDS council become genuinely multi-agent — independent agents with their own
context and tools, not one model role-playing personas — and if so, how, with the least cost and
grunt work?**

Constraints that any answer must satisfy (the hard filters):
- Runs on a **GitHub Actions cron** + the **git repo as shared state** — no standing server.
- The **daily heavy work stays on the Claude Max subscription** (no per-token API) if possible.
- **Solo researcher, cost-sensitive**, minimal new infrastructure to maintain.

Why it matters: the goal is a nuanced, accurate, comprehensive answer to the project's
trade-secret / clinical-data-as-investment question. Multi-agent is only worth doing if it moves
that answer forward more than the simpler fixes already shipped ([[40 - Evidence on ROI]]).
