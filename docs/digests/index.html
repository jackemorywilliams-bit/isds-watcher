Each weekly run is archived below, newest first. Open a date to read the formatted digest: its run summary followed by one annotated entry per surfaced development, with the source named, linked, and its URL shown in full.

What the runs show

Two views of the archive, built from each run’s recorded counts: how screening volume and watch-list leads shown have moved week to week, and which catalogue sources actually surface developments that reach the digest. No item has yet scored a true match (≥ the threshold), so the match line sits at zero throughout — the charts track screening discipline and watch-list leads shown, not findings.
